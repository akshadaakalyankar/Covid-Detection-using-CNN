
# Data Dictionary

## 1. Dataset Overview

| Field | Value |
|---|---|
| Dataset name | COVID-CTset — A Large COVID-19 CT Scans Dataset |
| Source | Kaggle |
| Task | Binary CT image classification |
| Classes | `covid` (positive), `normal` (negative) |
| Image format | TIFF grayscale CT images |
| Original image size | 512 × 512 pixels in the inspected samples |
| Model input size | 224 × 224 pixels |
| Label encoding | `normal = 0`, `covid = 1` |
| Annotation format | CSV files |
| Split strategy | Patient-level train, validation, and test splits |

Dataset source:
https://www.kaggle.com/datasets/mohammadrahimzadeh/covidctset-a-large-covid19-ct-scans-dataset

## 2. Dataset Organization

The dataset is accessed directly from Kaggle's input directory.

```text
/kaggle/input/datasets/mohammadrahimzadeh/
└── covidctset-a-large-covid19-ct-scans-dataset/
    ├── Annotation/
    │   └── CSV/
    │       ├── Patient_details.csv
    │       ├── train1.csv ... train5.csv
    │       ├── validation1.csv ... validation5.csv
    │       └── test1.csv ... test5.csv
    └── [CT image files]
```

The exact image subdirectory structure should be determined from the Kaggle dataset files. Images are resolved through the filename-to-path mapping created during data preparation.

The project does not require copying the dataset into a local `data/` directory.

## 3. Class Labels

| Class | Integer encoding | Description |
|---|---:|---|
| `normal` | 0 | CT image labelled normal/negative in the dataset |
| `covid` | 1 | CT image labelled COVID-positive in the dataset |

The labels represent the dataset annotations. A model prediction is not a medical diagnosis.

## 4. Dataset Metadata

| Field | Description |
|---|---|
| `filename` | Image filename used to locate a CT scan |
| `patient_id` | Identifier linking images to a patient |
| `class` | Image label: `normal` or `covid` |
| `image_path` | Runtime path to the image file |
| `split` | Assigned partition: train, validation, or test |

The exact CSV column names should be verified when constructing the manifest. `image_path` and `split` may be generated by the project rather than stored in the original CSV files.

## 5. Preprocessing

1. Read each TIFF image as a grayscale array.
2. Convert pixel values to `float32`.
3. Clip intensities using the per-image 0.5th and 99.5th percentiles.
4. Scale intensities to the range [0, 1].
5. Resize to 224 × 224 pixels using bilinear interpolation.
6. Apply training-only augmentation: random horizontal flip and small random rotation.
7. Replicate the grayscale channel into three channels.
8. Normalize using ImageNet statistics:

   - Mean: `[0.485, 0.456, 0.406]`
   - Standard deviation: `[0.229, 0.224, 0.225]`

Validation and test images are not augmented.

## 6. Data Splitting

The project uses patient-level splitting to reduce data leakage between training, validation, and testing.

| Split | Patients | Images |
|---|---:|---:|
| Train | 263 | 8,476 |
| Validation | 57 | 1,915 |
| Test | 57 | 1,667 |
| Total | 377 | 12,058 |

These counts correspond to the audited dataset and the custom split generated with `random_state=42`. Recheck them if the manifest, split seed, or dataset version changes.

The supplied CSV validation and test partitions should not automatically be treated as independent because overlap was observed during the dataset audit.

## 7. Known Limitations

- **Class imbalance:** The audited image manifest contains more normal images than COVID-positive images.
- **Patient-level correlation:** Multiple images may belong to the same patient, so image-level metrics may not represent patient-level performance.
- **Domain shift:** Differences in CT scanners and acquisition protocols may affect generalization.
- **Limited metadata:** The dataset's patient metadata and its suitability for further analysis should be checked before using demographic or clinical variables.
- **Preprocessing assumptions:** Per-image percentile scaling may affect intensity information and should be documented as a modeling choice.
- **Clinical limitations:** This project is for educational and research purposes, not clinical diagnosis or treatment decisions.
